# Invariantes

* Un pasajero nunca puede tener más de un asiento asignado en una misma reserva.
* La fecha de nacimiento de un pasajero nunca puede ser una fecha futura.
* Un servicio extra nunca se puede incluir en una reserva si no está disponible en los vuelos de esta.
* Una reserva siempre debe tener al menos un pasajero asociado.
* Una reserva siempre debe tener un único pasajero titular.
* Nunca se puede realizar el check-in de una reserva que no esté confirmada (pagada).
